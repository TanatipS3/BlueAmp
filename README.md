# BlueAmp

Lightweight Windows Bluetooth audio receiver with a transparent diagnostic layer.

## What it is
A system tray app that lets you stream audio from your phone to your PC over Bluetooth — and actually tells you what's happening when it doesn't work.

## Minimum Requirements
- Windows 10 version 2004 (Build 19041) or later
- .NET 8 Runtime
